AUTHORIZED SCOPE / USER DECISIONS (2026-11-16)
- User request:
  - Dashboard "Pending quality reviews" should select Flagged in the Scan Logs Status menu.
  - "Expiring stock" should set the scan date to today, and today should be the default.
  - The user asked for the scenario to be analysed first.
- Analysis:
  - The review rule was flagged OR confidence < threshold. New low-confidence scans are
    already flagged at save (fusion_engine auto_flagged), so un-flagged scans could never
    leave the queue.
  - The chip counts are all-time backlogs. All 15 at-risk scans were from Oct 21, so a
    today-only date would empty those lists.
- Decisions:
  1. "Flagged = the queue": dashboard._review = flagged; _successful = not flagged with a
     known confidence. The chip opens /logs?status=Flagged. Remove Flag clears a scan from
     the queue. The legacy attention=review becomes status=Flagged.
  2. "Today for normal Logs only": a plain /logs (paging and sorting kept) is replaced with
     ?date=<today, Manila> before the first request.
     - Filtered links (chips, Inventory, intakes, sources) show all dates, and the date box
       reads "All dates".
     - date=all is the explicit form: clearing the date sets it, and any filter change
       writes it when no date is set.
     - Reset and the Total card go to today.
     - Dashboard "View All Logs" and Recent Scans rows go to ?date=all.
