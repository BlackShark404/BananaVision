IMPLEMENTED
- Frontend transport: an HTTPS page calls its own origin for HTTP and WebSocket traffic
  (empty BASE_URL, wss on window.location.host). Plain HTTP keeps http://<host>:8000.
  VITE_API_URL and VITE_WS_URL remain explicit overrides.
- WebSocket: a ping event every 25 seconds while open, stopped on close, reconnect and
  unmount. Ownership, backoff and room behavior are unchanged.
- Media auth: withMediaToken adds the session as ?token= for Kiosk, Dashboard and camera
  calibration previews; the backend accepts a bearer header or query token. Evidence
  images under /captures remain bearer-only. Public QR tracking no longer renders camera
  images and states that evidence stays behind staff authentication.
- QR: VITE_PUBLIC_BASE_URL overrides the origin embedded in printed labels; trailing
  slashes are removed. Without it, labels keep the kiosk origin.
- Backend: get_media_user shares _resolve_user with get_current_user; the preview route
  requires a session; invalid fps still fails before capture. Production refuses missing,
  placeholder or shorter-than-32-byte APP_SECRET_KEY/JWT_SECRET_KEY and disables /docs,
  /redoc and /openapi.json.
- Proxy: deploy/Caddyfile serves frontend/dist and forwards /api, /captures and /health to
  127.0.0.1:8000. It binds loopback, accepts any Host (Funnel sends its public name),
  returns 404 for API docs and adds HSTS, CSP, X-Content-Type-Options, X-Frame-Options,
  Referrer-Policy and no Server header.
- Env/docs: backend/.env.example documents production secrets, trusted proxies and the
  LAN-compatible CORS example; frontend env comments describe same-origin and the public
  QR base. docs/remote-access.md now contains the full Option 2 procedure. Knowledge notes
  Frontend.md, Development Decisions.md and Testing and Validation.md are updated.
- Tests: backend/tests/test_camera_preview.py covers session requirement and header/query
  token selection; backend/tests/test_settings_security.py is new; the connectivity browser
  test covers the heartbeat.
