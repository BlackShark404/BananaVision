2. OFFICOM PT-210 HARDWARE & COMPATIBILITY PROFILE
================================================================================
- Product Name: OFFICOM PT-210 Portable Wireless Bluetooth Thermal Receipt Printer (58mm)
- Hardware Family: OEM MPT-II / POS-5802 / GOOJPRT PT-210 series.
- Printing Method: Direct Thermal line printing (requires heat-sensitive paper; no ink/ribbon).
- Paper Specifications:
  * Paper Width: 57.5 ± 0.5 mm (standard 58mm thermal roll).
  * Max Roll Outer Diameter: ≤ 40 mm.
  * Paper Type: Continuous thermal receipt paper (non-adhesive out-of-box).
- Print Head Dimensions:
  * Effective Print Width: 48 mm (384 dots per line).
  * Resolution: 203 DPI (8 dots/mm).
  * Printing Speed: 50–80 mm/s.
- Interface & Connectivity:
  * USB: Micro-USB or Type-C (detected as USB Printing Support or USB-Serial).
  * Bluetooth: Dual mode (Bluetooth 3.0 SPP + BLE 4.0; device name "MPT-II" or "PT-210", PIN 0000 or 1234).
- Power: 7.4V / 1500mAh rechargeable lithium-ion battery.
- Printing Protocol:
  * Hardware supports ESC/POS command set.
  * Native 2D ESC/POS QR command is GS ( k, but budget clones frequently have firmware flaws.
  * BANANAVISION DOES NOT USE ESC/POS DIRECTLY. BANANAVISION uses browser printing (window.print()).
  * Browser -> Windows Print Spooler -> POS-58 Driver -> Raster Graphics stream.
  * The Windows driver renders the QR image into raster bit images (GS v 0) automatically.

5. ZERO-CODE CONFIGURATION GUIDE (SCAN DETAIL & LOGS)
================================================================================
The OFFICOM PT-210 can print individual QR tags from ScanDetail.tsx and Logs.tsx
WITHOUT modifying any BANANAVISION code, following these exact setup steps:

A. HARDWARE CONNECTION:
1. Remove protective plastic tape from the battery terminals.
2. Insert 57mm thermal paper roll (smooth/shiny thermal side facing print head).
3. Connect printer to Windows PC via USB cable (recommended for station reliability)
   OR pair via Bluetooth (Settings > Bluetooth > Add device > MPT-II, PIN: 0000).

B. DRIVER INSTALLATION:
1. Run "POS Printer Driver Setup 58mm.exe" as Administrator.
2. Select Windows 10/11, printer model "POS-58".
3. If USB: Select port "USB001".
4. If Bluetooth: Check Windows Bluetooth Settings > More Bluetooth Settings > COM Ports.
   Note the OUTGOING COM port (e.g. COM3 or COM4). In driver setup or Printer Properties,
   assign port to that COM port (Baud: 9600 or 115200, 8-N-1, Flow Control: None).
5. Print Windows Test Page from Printer Properties to verify communication.

C. BROWSER PRINT SETTINGS (CRITICAL):
When clicking "Print Tag" in BANANAVISION:
1. Destination: Select "POS-58".
2. Paper Size: Select "58 x 297 mm" or "58(48) x Continuous".
3. Margins: Set to "NONE" (Default margins will clip the 40mm tag).
4. Options: UNCHECK "Headers and footers" (prevents wasting receipt paper on URL/date).
5. Scale: Set to "Fit to printable area" or custom "90% - 95%".

Issue 3: LOCALHOST ORIGIN ENCODING
- Severity: MEDIUM (Deployment blocker).
- Description: generateQRCodeDataUrl uses window.location.origin. In local station dev/kiosk mode,
  this produces http://localhost:5173/scans/..., which external phones cannot reach.
- Target File: frontend/src/lib/qrcode.ts.
- Fix: Allow an environment override (e.g. VITE_PUBLIC_TRACKING_BASE_URL) falling back to window.location.origin.

Issue 4: DELIVERY INTAKE BATCH LABEL OVERFLOW
- Severity: MEDIUM (Formatting defect).
- Description: DeliveryIntake.tsx opens popup with 300px image (overflows 48mm printable width) and
  shows a <button> that prints onto the thermal receipt roll.
- Target File: frontend/src/pages/admin/DeliveryIntake.tsx.
- Fix: Apply @media print { button { display: none; } } and constrain image to width: 40mm.

Issue 5: RECEIPT PAPER VS ADHESIVE LABELS
- Severity: OPERATIONAL / HARDWARE.
- Description: PT-210 is a receipt printer with a tear bar, not a die-cut label sticker printer.
- Fix: Station operators must load 57mm linerless/continuous thermal adhesive rolls or staple/tape receipts.
